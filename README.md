A program that draws one image summing up the world news of Thursday 19 November 2026: a newspaper front page led by the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, with the ICJ's Myanmar genocide ruling, the Kerch Bridge strike, the Gaza operation, the Gulf escalation, Anthropic's record IPO, Cyclone Akvan and COP31. Pure Node 22 standard library — no network, no model calls, fully deterministic: it renders the page with its own 5×7 bitmap font and PNG encoder and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
